# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is widely known for offering one of the broadest ranges of cloud services. It provides many services for computing, storage, databases, networking, security, analytics, and other cloud technologies, making it suitable for different types of organizations and projects.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that mainly uses Microsoft products. Azure works well with Windows Server, Microsoft 365, Active Directory, and other Microsoft technologies, making integration and management easier.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes services. Google has a strong background in AI technologies and was also one of the main organizations involved in the development of Kubernetes.

### 4. What similarities did you observe among the three cloud providers?

AWS, Microsoft Azure, and Google Cloud Platform all provide similar core infrastructure services. They each offer compute, storage, networking, and identity management services, although the names and features of their services may be different.
