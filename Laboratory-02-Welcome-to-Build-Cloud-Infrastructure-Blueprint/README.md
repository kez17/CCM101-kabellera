# Laboratory Activity 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on investigating and understanding the major components of cloud infrastructure. Using the KillerCoda Linux environment, the available operating system, compute resources, storage resources, and networking resources were examined and documented. The activity also included comparing the core infrastructure services offered by major cloud providers and creating a simple cloud infrastructure design.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate the hardware and software resources available in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Understand how different cloud infrastructure components work together.
- Create technical documentation using Markdown.
- Continue building a structured GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

Cloud infrastructure is composed of different resources that work together to support applications and services.

### Compute Resources

Compute resources provide the processing power and memory needed to run applications and services. Examples include the CPU and RAM of the Linux server.

### Storage Resources

Storage resources are used to store files, applications, databases, and other important data. Examples include disks and mounted file systems.

### Networking Resources

Networking resources allow communication between users, servers, and cloud services. Examples include IP addresses and network interfaces.

### Operating System

The operating system manages the hardware and software resources of a server. In this activity, Linux was used to investigate and manage the cloud server environment.

## Linux Commands Executed

| Command | Purpose |
|---|---|
| cat /etc/os-release | Displays information about the installed operating system. |
| uname -r | Displays the Linux kernel version. |
| lscpu | Displays detailed information about the CPU, including the CPU model and number of cores. |
| free -h | Displays the total and available RAM in a human-readable format. |
| lsblk | Lists the available storage devices and disk partitions. |
| df -h | Displays mounted file systems and available disk space. |
| hostname | Displays the name of the server. |
| hostname -I | Displays the IP address assigned to the server. |
| ip addr | Displays detailed information about the server's network interfaces and IP addresses. |
