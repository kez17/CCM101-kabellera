# Mission Reflection

For me, compute resources are one of the most important components because applications and services need processing power and memory to run. Without the CPU and RAM, a cloud server would not be able to process information or perform the tasks required by users and applications. Compute resources are also important because they directly affect the performance of applications and how quickly they can respond to users.

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. It allows administrators and cloud engineers to manage resources, run applications, configure networks, and automate different tasks using commands and scripts. Linux is also widely used in cloud environments because it can be customized depending on the needs of the organization.


Technical documentation is important before deploying infrastructure because it provides a clear record of how the system is planned and configured. It helps engineers understand the resources being used, avoid mistakes, and makes the infrastructure easier to manage and maintain in the future. Proper documentation also helps team members communicate and understand the purpose of each infrastructure component.


During this laboratory activity, I learned how to use Linux commands to investigate the operating system, CPU, RAM, storage, hostname, and IP address of a cloud server. I also improved my understanding of cloud infrastructure components and my skills in creating technical documentation using Markdown and GitHub.


My GitHub portfolio improved because I was able to add another organized laboratory project with complete documentation and supporting screenshots. This activity also demonstrates my growing understanding of Linux, cloud infrastructure, technical documentation, and the basic services provided by cloud platforms. It also gives me a record of the skills and activities I have completed during my cloud computing course.
