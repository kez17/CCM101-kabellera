
# Mission Reflection

Object storage is better suited for storing millions of photos because it is designed to store large amounts of unstructured data such as images, videos, and backups. Unlike traditional block storage, object storage stores each file as an object with its own data, metadata, and unique identifier. This makes it useful for applications that need to store and access many images.

Docker made it easier to deploy the MinIO storage server because I only needed to run a Docker command instead of manually installing and configuring all the required software. Docker also makes the application easier to start, stop, and manage inside a container. This helped me deploy MinIO faster and with fewer configuration steps.

A bucket is a storage container used to organize and store objects. In this activity, the bucket was named client-photos, and it was used to store the uploaded test file.

Large enterprise companies can protect their object storage data by keeping multiple copies of their data. They can also use backups, replication, and different storage locations so that the data can still be recovered if a physical server crashes. These methods help reduce the risk of permanent data loss.

My confidence in using the Linux command line is growing because I was able to use commands to deploy and check a cloud storage server. At first, the commands were unfamiliar, but following the steps helped me understand how Docker and MinIO work. This activity also helped me become more comfortable with cloud storage, containers, and basic Linux commands.
