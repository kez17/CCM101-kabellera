## Mission Overview

In this laboratory activity, I deployed a MinIO object storage server using Docker. I created a storage bucket named `client-photos` and uploaded a sample file to test the cloud storage system. I also learned how object storage is used to store large amounts of unstructured data such as images and files. This activity helped me understand how Docker can make it easier to deploy and manage cloud services. I also practiced using the Linux command line and accessing a cloud storage service through a web browser.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface.
- Create a storage bucket and upload files.
- Document cloud storage operations using Markdown.
