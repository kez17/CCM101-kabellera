# Mission 5: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed a MinIO object storage server using Docker. I created a storage bucket named client-photos and uploaded a sample file to test the cloud storage system.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface.
- Create a storage bucket and upload files.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Using Docker to deploy a cloud storage server
- Understanding different types of cloud storage
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Using Linux command-line commands
- Documenting cloud infrastructure using Markdown
