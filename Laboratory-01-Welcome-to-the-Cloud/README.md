# Laboratory 01 – Welcome to the Cloud
## Mission Overview
This exercise serves as my introduction to working within a Linux environment, covering the essential skills that form the foundation of cloud computing. I completed this activity using the KillerCoda platform, where I practiced navigating the system, running commands, and setting up my own portfolio repository on GitHub.

## Objectives
- Gain access to a Linux environment through KillerCoda
- Navigate and explore the operating system using commands
- Retrieve and review key system information
- Create, arrange, and manage files and directories
- Establish a repository on GitHub for version control
- Prepare and organize documentation using Markdown

## Activities Performed
- Connected to the Ubuntu Linux environment via KillerCoda
- Created a personalized user account and granted appropriate access permissions
- Verified account details, working directory, and system identifier
- Retrieved details about the operating system, kernel, processor, memory, and storage
- Constructed folders and documentation files for organizing work
- Built a complete portfolio structure and prepared it for publication on GitHub

## Linux Commands Used
- whoami, pwd, hostname
- adduser, usermod, su
- cat, uname -r, lscpu, free -h, df -h
- mkdir, nano, touch, cp

## Skills Learned
I learned how to create a user account and give it administrative access in Linux. I also learned how to check my current location, username, and system name. I can now view important system details such as the operating system version, kernel release, processor type, memory size, and available storage. I practiced making folders, writing files, copying documents, and keeping everything organized. I also learned how to write proper documentation using Markdown, save my work to GitHub, and understand why good organization matters in cloud computing.
