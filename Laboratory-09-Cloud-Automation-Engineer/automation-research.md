# Automation Research

## Bash Script
A Bash script is a plain-text file holding a sequence of commands that execute together as a single program, removing the need to type each instruction separately. The #!/bin/bash line at the top — called the shebang — specifies which shell should interpret the file, ensuring all syntax and behavior follows Bash standards consistently.

## Variables
Variables store values such as folder paths under a short, reusable label instead of repeating the full location every time. This simplifies reading and updating the script — changes apply in one place only — and reduces typing errors whenever the same path appears across multiple lines.

## Cron Job
A cron job is a built-in Linux scheduling feature that runs commands or scripts automatically at defined times without manual intervention. It serves a critical role in cloud operations by handling recurring tasks like backups and maintenance reliably on a fixed timetable, ensuring consistency even across large server fleets.
