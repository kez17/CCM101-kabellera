# Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: AWS

AWS is recommended for the startup because it provides a broad range of services that can support a mobile application as the company grows. The startup can begin with a small amount of infrastructure and increase its resources as the number of users increases. AWS also provides managed services that can reduce infrastructure management requirements. Because the startup has a limited budget, it should monitor resource usage and select cost-effective services.

### Recommended Services

1. Amazon EC2 – Application computing
2. Amazon S3 – Object and media storage
3. Amazon RDS – Relational database
4. Amazon CloudFront – Content delivery
5. AWS IAM – Identity and access management

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's identity and enterprise technologies, which can make migration easier. The university can also use Azure to create a hybrid environment while gradually migrating services to the cloud. This approach can reduce migration risks and allow the university to continue using its existing Microsoft expertise.

### Recommended Services

1. Azure Virtual Machines – Windows Server workloads
2. Microsoft Entra ID – Identity management
3. Azure Virtual Network – Cloud networking
4. Azure SQL Database – Relational database
5. Azure Backup – Backup and recovery

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud

Google Cloud is recommended because the company develops Artificial Intelligence and Machine Learning applications that require high-performance computing. Google Cloud provides AI and ML services, powerful computing infrastructure, GPUs, and other accelerators. The company can use these services to train and deploy machine learning models. Google Cloud also provides strong data analytics and Kubernetes capabilities that can support AI workloads.

### Recommended Services

1. Compute Engine – High-performance computing
2. Vertex AI – Machine Learning development and deployment
3. Cloud Storage – Dataset storage
4. Google Kubernetes Engine – Containerized AI workloads
5. BigQuery – Data analytics

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

AWS is recommended for the global e-commerce company because it provides scalable infrastructure and global cloud capabilities. The company can deploy applications across multiple Availability Zones and Regions to improve availability. AWS Auto Scaling can automatically increase or decrease computing capacity according to demand. Services such as Elastic Load Balancing and Amazon CloudFront can also help distribute traffic and deliver content to customers around the world.

### Recommended Services

1. Amazon EC2 – Application computing
2. Elastic Load Balancing – Traffic distribution
3. EC2 Auto Scaling – Automatic scaling
4. Amazon RDS – Relational database
5. Amazon S3 – Object storage
6. Amazon CloudFront – Global content delivery

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, scalability, and flexible infrastructure |
| Enterprise Organization | AWS | Large service portfolio and mature enterprise ecosystem |
| Microsoft Environment | Azure | Strong integration with Microsoft technologies |
| AI / Machine Learning | Google Cloud | Strong AI/ML services and computing capabilities |
| Kubernetes Deployment | Google Cloud | Strong Kubernetes capabilities through GKE |
| Global Web Application | AWS | Global infrastructure, scalability, and content delivery |
