## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three providers. Its services cover computing, storage, databases, networking, security, analytics, artificial intelligence, IoT, and application development.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works especially well with Windows Server, Microsoft 365, Active Directory, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), while also offering many AI and ML services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and supports many different workloads. Its large ecosystem provides flexibility for future projects, although the final choice should always depend on the organization's specific requirements.

## Service Comparison

The three cloud providers offer equivalent services even though the names and implementations are different.

Amazon EC2, Azure Virtual Machines, and Compute Engine provide virtual machine infrastructure. Amazon S3, Azure Blob Storage, and Cloud Storage provide object storage, while Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed Kubernetes services.
