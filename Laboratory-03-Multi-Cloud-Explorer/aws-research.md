# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a public cloud computing platform provided by Amazon. AWS offers a wide range of cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

AWS allows organizations to access computing resources on demand without having to purchase and maintain physical servers.

## Global Infrastructure

AWS has a global cloud infrastructure organized into geographic Regions and Availability Zones.

An AWS Region is a separate geographic area that contains multiple Availability Zones. Availability Zones are designed to be independent locations within a Region.

Organizations can deploy applications across multiple Availability Zones to improve availability and resilience.

AWS also operates a global network and edge locations that can help deliver applications and content closer to users.

## Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS services and resources.

Through the console, users can create virtual machines, configure networks, manage storage, control permissions, monitor resources, and manage billing.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity in the form of virtual servers.

EC2 can be used to host websites, applications, development environments, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service.

S3 can store files, images, videos, backups, logs, and other types of data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources.

It allows organizations to create virtual networks, subnets, routing configurations, and security controls.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources.

IAM allows administrators to manage users, groups, roles, policies, and permissions.

## Three Advantages

### 1. Wide Range of Services

AWS offers a large collection of cloud services for computing, storage, databases, networking, security, analytics, and artificial intelligence.

### 2. Scalability

AWS allows organizations to increase or decrease computing resources according to demand.

### 3. Global Availability

AWS has a large global infrastructure that allows organizations to deploy applications in different geographic locations.

## Typical Enterprise Use Cases

AWS is commonly used for:

- Web application hosting
- Mobile application backends
- E-commerce systems
- Enterprise application migration
- Backup and disaster recovery
- Data analytics
- Artificial intelligence and machine learning
- High-performance computing
- Internet of Things applications
