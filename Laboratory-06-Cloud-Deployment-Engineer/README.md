# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview

Mission 6 introduces the deployment of a private cloud storage system using Docker Compose. The application is built from two services, with Nextcloud handling the web application and MariaDB handling the database.

## Objectives

* Describe the basic structure of a two-tier application.
* Understand how services are defined in Docker Compose.
* Create a YAML configuration through the Linux terminal.
* Deploy a multi-container application.
* Recognize the role of Infrastructure as Code.
* Document the activity using Markdown files.

## Commands Executed

```bash
mkdir nextcloud-deployment
cd nextcloud-deployment
nano docker-compose.yml
docker-compose up -d
docker-compose ps
docker-compose down
```

## Skills Learned

This activity allowed me to practice Docker Compose, YAML syntax, Linux terminal commands, container communication, environment variables, application deployment, and technical documentation.
